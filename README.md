# Gestión de Países en Python

## Descripción

Este proyecto fue desarrollado como Trabajo Práctico Integrador para la materia **Programación 1** de la **UTN Regional Mendoza**.

La aplicación está escrita en Python y permite gestionar información sobre distintos países utilizando un archivo CSV como almacenamiento de datos. Entre sus funcionalidades se incluyen agregar, actualizar, buscar, filtrar, ordenar y obtener estadísticas sobre los países registrados.

## Integrantes

- Alejo Reinoso

## Funcionalidades

- Mostrar todos los países.
- Agregar un nuevo país.
- Actualizar la población y superficie de un país.
- Buscar países por nombre.
- Filtrar por continente.
- Filtrar por rango de población.
- Filtrar por rango de superficie.
- Ordenar por nombre, población o superficie.
- Mostrar estadísticas generales.

## Tecnologías utilizadas

- Python 3
- Módulo `csv`
- Listas
- Diccionarios
- Funciones
- Archivos CSV

## Cómo ejecutar el programa

1. Tener Python 3 instalado.
2. Descargar o clonar este repositorio.
3. Asegurarse de que el archivo `paises.csv` se encuentre en la misma carpeta que el programa.
4. Ejecutar el archivo principal:


python main.py


## Ejemplo de uso

- Seleccionar la opción **2** para agregar un nuevo país.
- Seleccionar la opción **4** para buscar un país por nombre.
- Seleccionar la opción **7** para visualizar estadísticas del conjunto de datos.
